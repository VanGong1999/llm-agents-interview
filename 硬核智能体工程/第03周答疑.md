## 2. DeepSeek harness 后续：数据隐私与「开源权重模型会不会回传」

### 2.1 Greg 对 DeepSeek harness 的态度（仍是 novelty）
- Greg 澄清：第 5 课演示 DeepSeek（Carnis/Cordis）更多是**教学目的**；他还没想通「我为什么要定制那个 harness」——它对 Greg 仍是「新奇感」。
- 关键前提：**要把它用在一个自己真正在乎的东西上，而不是玩具例子**，才能真正理解「能定制 harness」相对「用现成 harness 调用 DeepSeek」的价值差异。
- 观察：那个 DeepSeek harness 的 GitHub repo 涨星速度，是**近代历史里除 OpenClaw 之外最快的**。
- **hook（钩子）是什么？**——Greg 认为是「**方法的新奇性**」：你可以改它的 runtime、随心定制。人们本来就爱定制 agentic dev 流程周围的一切。
- 这其实也是当年 **Pi** 的主打卖点：超级 bare bones harness + 插件/扩展能力。

### 2.2 「数据属于中国」与数据隐私
- DeepSeek harness 的一个缺点：**只能用 DeepSeek 模型**（如 DeepSeek V4 Pro），而它不是 Greg 的 go-to 模型。
- 后来 Greg 修正：Prime Agent 那边其实**可以加任何 provider**（但按 API credit 付费，不是订阅制）——这反而给了 DeepSeek 一点优势，因为它**极便宜**。
- 但代价是：**「你所有的数据都属于中国（all your data are belong to China）」**——如果这对你在意的话。
- Greg 的补充：多数美国公司会**明说**是否用你的 traces 训练，但对中国 domicile 的模型，「没有所谓数据隐私这回事」。

### 2.3 Meta 的 Muse Code：用「免费 contributor」明牌换数据
- 例子：**Meta 刚发布的 Muse Code** 有两个 Muse Spark 模型：
  1. 一个按 input/output 收**更高价**；
  2. 另一个叫 **contributor**，**基本免费**——但 Meta 会「吸走你几乎所有代码」，因为你的代码会被写进 agent 的 session log。
- 关键：Meta 对此**非常直白**——选那个免费模型就等于同意这件事。这就是「你的 trade-off」。

### 2.4 核心讨论：本地 provider 跑开源权重，模型会「打电话回家」吗？
- 学员的假设：如果你找一家**美国本地的 provider** 跑任何开源权重模型（DeepSeek / GLM / Kimi K3 都行），**模型本身不可能「打电话回家（phone home）」**——因为那需要在中国数据中心 provisioning 才能发生。
- Greg 基本认同，并补关键点：**这些 provider 不是「passthrough 代理到 DeepSeek 平台」**——他们拿的是**开放权重（open weight）模型，自己托管、自己跑推理计算**，而不是转发到 DeepSeek。
- 学员自嘲：「这是我的基本假设，但我需要一个更聪明的人告诉我这是真的。」Greg：「我能想到的一切都指向这是真的。」

### 2.5 Fireworks 怎么拿到 DeepSeek？
- 学员问：**Fireworks（旧金山的 provider）是怎么拿到 DeepSeek 的？** 是把二进制直接 ship 给他们吗？
- 结论：如果模型在 **Hugging Face 上开放权重**（DeepSeek / Kimi 都是 open 的），那 Fireworks 应该就是**自己托管、自己跑推理**，而不是转发到中国。
- 旁支讨论：要跑一个 **2.8 万亿参数**的模型，你得是 Fireworks 这种级别的 provider（或当年的 Grok 级别），有足够的推理算力。

## 3. 自托管经济学：为什么「自己跑模型」不划算

### 3.1 模型体积
- **Kimi K3**：**2.8 万亿参数**；在 Hugging Face 下载是 **1.56 TB**；约 **96 个文件、每个 ~17 GB**（分区文件）。
- **DeepSeek V4 Flash**（不是 Pro）：**167 GB**。
- 结论：普通电脑**连下载都做不到，更别说 serve**。Greg 调侃「没有任何消费者有理由去按下载」。

### 3.2 关键区分：是 GPU 显存，不是硬盘空间
- 要 serve 模型，你得把整个模型**塞进内存（GPU 显存）**，不是硬盘。
- 例子：Kimi K3 未量化要 ~5.6 TB（转录此处有混乱，Greg 中途纠正 Gemini 的胡说）。

### 3.3 NVIDIA 芯片代际与成本（本场最硬核的算账）
- 各代显存：
  - **H100**（略旧，显存小）
  - **H200**：**141 GB** 显存
  - **B200（Blackwell）**：**192 GB**
  - **B300（Blackwell Ultra）**：**288 GB**
- 跑 Kimi K3 需要**至少 5 块 Blackwell Ultra**。
- 成本：一块 B300 DGX（单 Blackwell Ultra）零售 **$8 万–12.5 万**；整体落地大约 **$75 万–$100 万**才能 serve。
- 对比：通过 API 用这些模型，**每 token 只要几分钱**，几乎免费。
- 结论：**「自托管有点蠢，除非你真的想要本地 provenance（来源/主权）」**——就目前而言，经济学不成立。
- （补充：`local llama` 是自托管最火的 subreddit，但更像「自制电脑俱乐部」，没人在干正经事。）

### 3.4 Greg 的 Mac Pro M2 Ultra 经历
- Greg 桌子下有一台 **Mac Pro（M2 Ultra）**，但只买了 **64 GB RAM** 的版本（买早了，没赶在 memory crunch 前买 128/192GB；而且**无法升级**，因为内存在芯片上）。
- 他跑过 **Ollama** 上的 Llama 量化模型：能出输出，但**模型很烂（crappy quantized）**，**写不了代码**。
- 反思：「我拿它干嘛？不如直接用 ChatGPT。」
- 结论：**在自己机器上跑本地模型「永远会很烂，literally 很烂」**，除非其它方案变得很贵。

### 3.5 例外：嵌入式 / 本地权重模型的未来
- 真正的机会在**嵌入式本地权重模型**：如果能塞进 iPhone（如果不是那么 lock down），就能**把模型跟 app binary 一起 ship**，不用花大钱调 API。
- Greg 相信 Apple 在设计下一代芯片组时正在认真考虑这个（也契合 Apple 的「数据隐私」心智）。
- 现实障碍：像 **DGX Spark**（128GB 桌面机）都装不下一个 DeepSeek V4 Pro Flash（至少需要两台），所以**现在还不是时候**。

## 4. Torty 现场演示（Greg 的产品）

### 4.1 名字由来
- **Torty** = tortoise shell cat（**玳瑁猫**）的昵称「tortie」。
- 双关：`torty.sh` 域名——「shell」既指**管理你的 shell**，又指 tortie 的「tortitude」（玳瑁猫**有主见、忠诚、警觉、守护你**），这正是产品的「禅意」：**警觉地管理你的 session shell、不丢失它们**。
- 另一个隐喻：tortie 是「多种东西的混合」，而 Torty 正是「混合使用大量不同 agent session」的工具。
- Greg 的两只猫：**Caddy** 和 **Gucci**（Gucci 是那只最像 tortie 的黑猫）。
- （顺带：Greg 说 `torty.sh` 是他见过**最好的域名**——「tortoise shell」双关。）

### 4.2 新功能（正在做最终测试、即将发布的大版本）：SSH 多机管理
- 可以**配置多台机器**（如他的另一台 Mac Pro），用 **Tailscale** 帮忙发现机器名，建立连接后，创建新 session 时可以选择**在哪台机器上运行**。
- 效果：**在一个窗口里友好地管理多台机器上的 shell**，关掉后能重新拉起，后台持续运行。
- 现场演示：打开一个 Claude shell、一个 Codex shell（项目是 Grok build 代码库），做 multiplexing。

### 4.3 最喜欢的功能：Zen mode
- 快捷键 **Shift + Command + Enter**：**放大/缩小** shell，去掉周围所有 chrome，进入纯净的 shell 视图。
- Greg 说他现在**天天用**这个。

### 4.4 其它细节
- **对比度定制**：高/低对比度（**不做白色主题**，因为效果不好）；highlight 配色可改。
- **Provider 扫描**：会扫描你机器上装的所有 provider，给出「canonical 安装命令」（一个 copy 字符串），避免重复安装。
- **扩展性**：通过 **torty config + `agents.json`** 可以加开箱不支持的自定义 agent（如 AMP）——你的 agent 会读 torty config、更新 `agents.json`，**不用等新 build**。
- 还能管理 **Pi session**（依赖你的 `.zshrc`）。
- 当前最新版 **3.1**（会 auto-update）。

### 4.5 发布与遥测
- Greg 没有任何用户遥测（**purposely no telemetry**）；仅有的 telemetry 是 vendor 的 Spec Story 二进制里 baked-in 的（当前 build 里**已损坏**，下版修复），且除非你登录 Spec Story 否则不会回传。
- 所以他「**完全不知道谁在用**」——只能靠 GitHub release 的下载数猜（排除自己重复下载）。

## 5. AI 与教育（本场最长的实质讨论）

### 5.1 引出问题：Reed Hastings 网络研讨会——老师会变成什么？
- 学员抛出「left field」问题：他 K-12 教育背景，前几天一个 webinar（Reed Hastings 等）在探讨——**当 AI 好到能当「内容专家 / 教学专家 / 激励与 engagement 专家」时，老师会变成什么？**
- 想象：AI 已经能理解上下文和内容，假设再解决「怎么吸引并维持人（尤其孩子）的动力」，那老师剩下什么？

### 5.2 Greg 的短答案：牧羊人（Shepherd）+ 社会化
- 关键词：**Shepard（牧羊人）**。把 Alpha School 推到极致（孩子在没有真老师的教室里、对着 iPad 版老师头像自学），你就会明白：
- **上学不只是学乘法表，而是学会当一个「社会生物（social creature）」**。
- 老师做的远不止教学，他们是**导师（mentor）**，帮你解决人际/社交动态问题——**这部分不会消失，AI 无法替代人类**。

### 5.3 Jack 的补充：头号工作是「保姆」+ COVID 冲击 + 青少年的反弹
- Jack（有两个高中生，妻子 Robin 当了 6 年中学老师）补充：
  - 即便在运转良好的学校，**头号工作其实是「babysitter（照看孩子）」**：需要一个地方让孩子去、不惹麻烦、不受伤、不互相伤害——正面说法是**社会化（socialization）**。
  - **COVID 让社会化严重受损**，很多孩子至今仍在恢复。
- **青少年的反弹（backlash）**：孩子们**本能地**理解「你必须 struggle bus（挣扎）才能学会东西」；用 AI 的错误方式太容易**跳过挣扎**，于是你什么都没学到。
- Jack 的孩子原话：**「我一旦理解了这东西，就会用 AI；但我不会用 AI 来帮我理解这东西。」**

### 5.4 人类教师的溢价 / 私立学校「不用 AI」
- Greg 推断：当 AI 学习界面好到能 quasi-替代部分教学，反而会**为人类教师创造溢价**。
- 因为年轻一代对 AI 有反弹 + 他们够聪明（通过社交媒体）意识到 AI 对工作/职业/前景意味着什么。
- 结果：**会有家长愿意为「我们在课程里不用 AI」的私立学校付溢价**——过去他们本就会为私立学校付费，现在会付得更多。
- 一个「Bizarro」结局的想象：AI 压缩了教学时间，孩子们都回到户外、重新投入真实世界——这会是很有意思的结果。

### 5.5 大学：2 sigma 之外，「买的是关系」
- **2 sigma 方法**（Bloom 的 2 sigma 问题）：一对一私教能让教学效果提升 2 个标准差。AI 在「纯知识传输」上潜力巨大，接近这个私教效果（就像我们日常跟 Claude/Codex 对话）。
- 但**人们真正看重大学的不是知识传输**：
  - 大学是「**半进半出**」的 formative 经历：离开父母家、但还没真实世界的责任。
  - **买的是关系/体验**：网络、socialize、实习/外派、出国、俱乐部——「**你认识谁、他们看重你什么，而非你知道什么**」。
  - 美国 top 100 大学能继续 hold 住，因为它们在城市、有 access 到人脉和机会，这些**盯着电脑得不到**。
- 真正会难受的是**掠夺性、盈利性、不提供校园体验的学校**（如 Strayer）——它们没有那个护城河。

### 5.6 文凭的解耦（科罗拉多社区学院 / 通用文凭颁发实体）
- **文凭（diploma）是大学垄断的东西**。有意思的案例：**科罗拉多州**一所社区学院偷偷通过了全州政策，允许它们**认证文凭**——学生可以说「我不去任何正式学校，自己学，CCD 给我发文凭（不是 GED，是 diploma）」。
- 由此引出想象：如果有一个**通用文凭颁发实体**能验证并授予，就能实现「**我们不在乎你在哪学、怎么学，我们给你盖章**」的解耦——大学当然会恨它、永远抗争。

### 5.7 线上学位（Georgia Tech / Greg 的 Berkeley 2U）
- **Georgia Tech Online Masters**：近 10 年的前沿案例。非常刻意地让「这是 Georgia Tech 学位，不是 Georgia Tech 线上学位」，保持课程严格；但仍在「文凭价值/雇主是否同等看重」上有挑战。
- **Greg 的 Berkeley 硕士**：通过 **2U** 平台（90% 虚拟），但要 GMAT/GRE、小 cohort（~15 人）、还有**immersion weeks（沉浸周，回校园一两周）**；毕业典礼也在 Berkeley 礼堂。他对「刻意保持真实/认可」这点很欣赏。
- 共识：研究生学位本来就该这么做（除非你读博或读 MBA——MBA 才全是社交）。

### 5.8 成本疯狂（$800k、劳动通缩）
- 朋友家两个孩子：一个 Tufts、一个 Wake Forest，**累计花了 $80 万**；女儿毕业后只拿到 **$5–6 万**年薪的工作。
- 对比：三人当年上大学，四年花十几万就算多了；现在**四倍成本，出来起薪和 20 年前一样**——因为**劳动力实际工资通缩（labor deflated）**，经济学「完全倒挂」。
- 结构：学费 list price 约 $7 万，**大多数人实际只付 list 的 50–60%**（国际生、富学生付全价）；食宿再加 $1–1.5 万。
- 痛点：私立学校有巨额 **endowment（捐赠基金）**，却（除哈佛等少数）不用来摊薄多数人的成本；行政臃肿（administrative bloat）。

### 5.9 「别再说 CS 是黄金之路」+ Jeff 的故事
- Greg 现在**不再建议「去学计算机科学」**，因为不确定那还是黄金之路；更建议**去追求你极度热爱、已经追了五年的创造性事业，去建立连接**。
- **Jeff 的故事**（LinkedIn 认识、前 USAID/外交政策、现在圣迭戈做咨询）：
  - 用 Claude 做两件事：**go-to-market 情报**（内部）+ **analyst briefs**（外部第一产品）。
  - 但**完全没有「软件怎么构建」的 mental model**：数据是本地 flat-file JSON + GitHub，不知道「持久存储 / 多租户数据库 / 登录 / PR / EPD 小队」这些概念。
  - Greg 给他看 Superbase 后端、解释 EPD squad 怎么工作（写代码→本地 commit→测试→push GitHub→开 PR→别的工程师 review）。
  - 启示：**「如果你不知道要问什么，就有一整片知识你完全接触不到。」** 这正是跟 AI 学习的最大挑战。
- 所以结论：**不必读 CS，但至少要学一两门（如 web 设计/开发）建立 foundational knowledge**，知道该往哪深入——被迫学反而有回报。

### 5.10 再培训 / 技能升级的商业机会
- 有一个巨大的「填补个人知识缺口」的需求（无数人兴奋想用 AI，却不知道第一/二/三步是什么）。
- 但问题：**这些人不会自己掏钱**。除非：
  - 公司把「reskilling/upskilling」算进**企业培训预算**（为可能的裁员做准备）；
  - 大组织把「再培训」作为 **offboarding/severance（遣散）** 的一部分（「我们出钱，有个机构帮你培训+找下一份」）——Greg 说这其实是有的，但他自己经历过的裁员（IBM）只给**纯现金遣散费**，没这种服务。
- 难点：这是**结构性失业**（不是摩擦性），尤其对年长、已在岗多年的人，重新学 agentic engineering 很难；除非有雇主/政府/企业联盟付费，否则难成生意。

## 6. 游戏、收藏品与爱好（社交闲聊，但有几个有意思的点）

### 6.1 Greg 的三款游戏（20 年只玩这三款）

### 6.2 游戏经济学
- **Diablo 4**：总收入已破 **$10 亿**；发售时是**史上卖得最快的游戏**，首周 **$6 亿**（含预售）。

- 为什么值：算「**每美元的娱乐时长**」是最划算的娱乐之一。Greg 在 Dota 2 十年累计 **2500 小时**（≈一整年工作时间），只花了 **~$150** 买皮肤。

### 6.3 万智牌：收藏品市场 = 股票市场
- 万智牌是**最贵的游戏**（Greg 不建议入坑）。但**纸牌版是他做过最好的投资之一**：卡片升值，因为「不再重印」。
- 收藏品市场（Pokemon、Magic）**暴涨**，流动性巨大。Hasbro 现在拥有 IP（买了 Wizards of the Coast，也是 D&D 的母公司）。
- **Magic FY25 收入 = $17 亿**（Hasbro，公开数据）。
- **MagicCon Vegas**：3 万人；供应商云集，**交易额以千万甚至上亿计**。
- **MTG Stocks.com**：像股票市场一样看卡片价格（涨 40% 跌 40%）。
- eBay 早期最热交易之一就是买卖万智牌（高价值、低重量、装信封就行）。
- 学习曲线残酷：要懂 formats、metagame、百科全书式的牌池知识，才能预测对手（回合制）。

### 6.4 Jake 的爱好：飞蝇钓 + 桌上足球
- **桌上足球（foosball）**：家里有张 **1991 年 Tornado 桌**（棕色大理石饰面，250 磅），朋友 Bob（波士顿消防员，开卡车）帮他从隔板拖进地下室——报酬是「**披萨 + 啤酒**」（那条「我认识个开卡车的人」的推文）。

- 入门故事：科罗拉多 Colorado Springs 西边 **South Park** 有栋 log cabin，后面那条河被全球钓客称为 **Dream Stream**；给姐夫买的生日礼物是一次向导带队钓，Greg 一竿钓上巨鱼、姐夫钓了条小鱼，那张照片在 Greg 妈妈冰箱上挂了很多年。

### 6.5 Yeti 冷藏箱（bear-proof）

## 附：本场核心概念 / 术语速查

| 术语 | 含义 |
|---|---|
| **Open weight（开放权重）** | 模型权重公开（可下载），如 DeepSeek/Kimi/GLM；区别于仅 API 访问 |
| **Phone home（回传）** | 模型/软件把数据偷偷发回厂商；本地 provider 托管开放权重则无此问题 |
| **Passthrough proxy** | 直接转发请求到原厂商平台（vs 自己托管权重跑推理） |
| **Contributor model（Muse Code）** | Meta 的免费模型，代价是代码被写进 session log 用于训练 |
| **MoE（Mixture of Experts）** | 混合专家架构，DeepSeek 率先带火，让小模型在窄领域很强 |
| **Quantization（量化）** | 压缩模型精度以塞进内存；量化过度→模型「很烂」 |
| **Blackwell Ultra（B300）** | NVIDIA 最新 GPU，288GB 显存；跑大模型需多块堆叠 |
| **2 sigma（Bloom）** | 一对一私教可提升 2 个标准差；AI 在知识传输上逼近此效果 |
| **Struggle bus** | 「必须挣扎才能学会」——青少年对 AI 依赖的本能反思 |
| **Diploma decoupling（文凭解耦）** | 把「学习」与「授证」分离（科罗拉多社区学院 / 通用文凭实体） |
| **EPD squad** | 工程/产品/设计小队（Jeff 缺失的软件开发 mental model 之一） |
| **Structural unemployment** | 结构性失业（vs 摩擦性），再培训生意难做的原因 |
| **Tenkara（天展钓）** | 极简飞蝇钓：竿+线+fly，无 reel |
| **Sous vide** | 低温慢煮（真空水浴）烹饪法 |
| **Bear-proof / bear canister** | 防熊冷藏箱 / 防熊罐（露营必备） |
| **Tortitude** | 玳瑁猫「有主见、忠诚、警觉」的性格；Torty 产品的禅意 |
