## 简介

这是一门关于**构建智能体（agent）**的短课程：语言模型反复选择下一步动作，程序执行该动作，结果再影响下一次选择。全书面向会编程、具备基础概率知识、希望理解智能体系统**为何**如此设计（而不只是如何调用某个框架）的读者。

核心图景是第 1 章的「智能体地图」：模型是相对固定的随机策略（policy），工程师主要设计其周围的**编排层（harness）**——上下文如何构建、有哪些工具、门控是否放行、记住什么、何时停止——并以评估度量设计是否更好。一句话说：

> 智能体工程，就是围绕一个固定的、随机的策略设计编排层，并配上告诉我们某种设计是否更好的度量。

贯穿示例是一个带 bug 的小仓库（含恶意 README 指令）：智能体需找 bug、修代码并通过测试。配套代码在原书提及的 `agent_engineering_code` / `miniagent`（约 400 行标准库 Python）。

本目录为全文中文 Markdown 译本，插图自 PDF 渲染截取，放在 `images/` 下。
